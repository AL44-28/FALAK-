# FALAK V2.1 · Mission Control

واجهة شبكة أقمار LEO فوق السعودية بصفحتين: **Dashboard** و**Scenarios**. تعرض الصفحة الرئيسية الأرض والأقمار والمدارات، ولوحة القمر المختار، وخريطة عامة لمستخدمي المنطقة. تعرض صفحة السيناريوهات خمس مساحات مستقلة لكتابة Python وتشغيله وحفظ البيانات والنتائج.

## افتحي المشروع

1. فكّي ضغط الملف كاملًا في مجلد جديد.
2. افتحي **`OPEN_PREVIEW_WINDOWS.bat`** بالنقر مرتين.
3. يفتح المتصفح تلقائيًا. أبقي نافذة التشغيل مفتوحة أثناء المعاينة.

هذه **المعاينة المحلية فقط** تحتاج Python 3 المثبت على جهازك. يفضّل المشغّل Python 3.11 ثم يحاول Python 3 المتاح. لا يحتاج MATLAB أو FastAPI أو Uvicorn أو تثبيت حزم عند الفتح. يعرض ملفات جاهزة ويختار منفذًا محليًا متاحًا تلقائيًا. لا تشغّلي إعادة بناء البيانات لفتح الداشبورد.

إذا لم يفتح المتصفح، انسخي الرابط الظاهر في نافذة التشغيل. Ctrl+C يوقف المعاينة. لا تفتحي `site/index.html` مباشرة؛ تحميل البيانات يحتاج رابط المعاينة أو الاستضافة.

**عند نشر `site` على GitHub Pages، تفتحين الرابط من المتصفح دون Python محلي أو نافذة تشغيل مفتوحة.** المستودع المستهدف الجديد هو `AL44-28/falak-mission-control`، ولم يتم تأكيد رابط النشر العام بعد. الحزمة جاهزة للنشر، وليست وحدها دليلًا على اكتمال النشر أو التحقق من الرابط.

## الصفحة الرئيسية

- **المشهد الفضائي:** اسحبي لتدوير الأرض، واستخدمي العجلة للتقريب. Overview يعود إلى السعودية، Region يركّز على المدينة، وFollow يتبع القمر المختار. الألوان تميز المدارات والأسماء، مع بقاء خامات جسم القمر المعدنية والألواح الشمسية.
- **لوحة القمر:** الاختيار اليدوي مخصص لفحص القمر ونموذجه وموقعه وارتفاعه وسرعته وميله وترددي UL وDL. `Users covered` يعرض الرؤية الهندسية، و`Link test` نتيجة تجربة ذلك الرابط. هذان الرقمان لا يحددان ألوان خريطة المنطقة.
- **Regional Network:** خريطة السعودية والمدن الخمس، وبجانبها مستخدمو المدينة المختارة. تتحدث ألوانهم تلقائيًا حسب الأقمار المخصصة لخدمتهم في وقت المحاكاة؛ لا تحتاجين تبديل القمر يدويًا ليتصل المستخدم بقمر آخر. اختيار قمر مختلف في اللوحة الجانبية لا يغير هذه الحالات.
- **تفاصيل المستخدم:** اضغطي على المستخدم لعرض القمر الخادم والقمر المخصص له وحالة التسليم وSNR وBER وهامش التصميم ومعدل البيانات. تتبع التفاصيل رابط الخدمة التلقائي، بما في ذلك انتقال الخدمة بين الأقمار.

تمت إزالة لوحتي **Orbital Pass** و**Spectrum** من الصفحة الرئيسية لتبقى المساحة للمشهد وخريطة المستخدمين.

ألوان المستخدمين تتبع **الحزم المحاكية التي سُلّمت عبر القمر الأساسي المخصص في كل عينة**:

| اللون | الحالة |
|---|---|
| أخضر — Strong | وصول 95% أو أكثر من الحزم في كل من الرفع والتنزيل، مع وجود وصول هندسي حالي |
| برتقالي — Weak | وصول حزم في الاتجاهين، لكن أحدهما أقل من 95% |
| أحمر — No connection | لا يوجد رابط مخصص متاح حاليًا، أو لم تصل حزم في أحد الاتجاهين |

النافذة آخر عشر عينات من ثانية واحدة، أو العينات المتاحة عند البداية. تحتفظ النافذة بتاريخ الخدمة عند انتقال القمر، ولا تبدأ سجلًا جديدًا كلما حدث handover. مجرد ظهور قمر في السماء لا يعني تخصيص حزمة للمنطقة؛ إذا لم تُخصص خدمة تُعرض الحالة وسببها الفعليان.

## صفحة Scenarios

تحتوي الصفحة على **Scenario 1 إلى Scenario 5**. يمكن تعديل أسماء المساحات، ولكل مساحة كودها ومخرجاتها ورسومها. يُحفظ الاسم والكود في المتصفح؛ أما المخرجات والرسوم وسياق التشغيل فتظل مستقلة أثناء الجلسة وتُمسح عند إعادة تحميل الصفحة، لذلك صدّري ما تريدين الاحتفاظ به. أُزيلت التبويبات السابقة الخاصة بالاستعادة ومختبر الاحتمالات وتحليل الرابط من الواجهة؛ أصبحت التجارب داخل مساحات Python الخمس.

اكتبي الكود واضغطي **Run Python**. التنفيذ حقيقي داخل المتصفح باستخدام NumPy وMatplotlib؛ لا يحتاج تثبيت Python على جهاز من يفتح الموقع المنشور. أول تشغيل يحتاج الإنترنت لتحميل بيئة Python، بينما فتح الداشبورد لا ينتظر هذا التحميل. تعرض المساحة المخرجات والأخطاء والرسوم، وتوفر Cancel وReset runtime.

تتيح أدوات التصدير حفظ الكود `.py`، وسياق البيانات `JSON`، وسجل الرابط `CSV`، ومستخدمي المنطقة `CSV`، ونتائج الكود `CSV`، والرسوم `PNG`. تستخدم صادرات البيانات آخر سياق تشغيل محفوظ للمساحة، أو الاختيارات الحالية قبل أول Run. يتضمن JSON أيضًا الكود والمخرجات والنتائج القابلة للتصدير. ترتبط نتائج التشغيل بالاختيارات وقت الضغط على Run؛ تحريك زمن المحاكاة بعد ذلك لا يعيد تسمية نتيجة سابقة على أنها نتيجة جديدة. التفاصيل وأسماء البيانات متاحة في [دليل Python](docs/PYTHON_WORKSPACE.md).

## ما الذي تمثله النتائج؟

المشروع **محاكاة اصطناعية** بعشرة أقمار: Suhail، Thurayya، Shira، Jawza، Nasr، Barq، Shihab، Afaq، Madar، Saraj. لا يمثل بثًا حيًا أو مواقع أقمار سعودية حقيقية. يبدأ السجل عند 2000-01-01 00:45:45 UTC، مع 6001 عينة من T+0 إلى T+6000 ثانية.

عند البداية تقع نقاط إسقاط **Jawza وShihab وAfaq** داخل حدود السعودية حتى ما قبل T+81 ثانية محاكاة، وتظل الأقمار الثلاثة مرشحة هندسيًا لجميع مستخدمي المناطق حتى ما قبل T+133 ثانية. هذه نافذة مختارة وليست تغطية ثلاثية مستمرة أو تخصيص 15 حزمة متزامنة. النموذج يخصص حزمة منطقة واحدة لكل قمر وفق السجل المحسوب، لذلك قد توجد منطقة بلا تخصيص رغم وجود مرشح هندسي.

تظل معادلات الراديو وBER وقدرات الإرسال وهامش التصميم كما هي. اللون الأخضر يلخص تسليم الحزم الحديث؛ لا يعني أن هامش التصميم موجب أو أن الاعتمادية طويلة الأمد مضمونة. تفاصيل التغيير والتحقق في [V2_1_CHANGES.md](docs/V2_1_CHANGES.md)، وشرح النموذج في [FALAK_INTERFACE.md](docs/FALAK_INTERFACE.md).

## النشر والتعديل

مجلد **`site`** هو الموقع الثابت الجاهز. انشري محتوياته بحيث يكون `index.html` بجانب `assets` و`vendor` و`data` وملفات JavaScript. لا يلزم نشر مجلد Python أو النسخ الاحتياطية. المسارات النسبية مناسبة لموقع GitHub Pages داخل مستودع. النشر العام يظل خطوة منفصلة عن حفظ هذه الحزمة. خطوات الرفع والإعداد في [GITHUB_PAGES.md](docs/GITHUB_PAGES.md).

| التعديل | الملف |
|---|---|
| ترتيب الصفحة | `site/index.html` |
| الثيم والمسافات | `site/style.css` |
| التنقل والاختيارات والزمن | `site/main.js` |
| الأرض والأقمار / النموذج الجانبي | `site/scene.js` / `site/scope.js` |
| خريطة المنطقة والمستخدمون | `site/users-viz.js` |
| حسابات الخدمة التلقائية | `site/simulation.js` |
| صفحة السيناريوهات | `site/scenarios.js` و`site/scenarios.css` |
| مساحات Python والتنفيذ | `site/python-workspace.js` و`site/python-worker.js` |
| الصور والنماذج والخريطة | `site/assets` |
| العناصر المدارية | `python/data/omm.csv` |
| مرجع الحسابات والتصدير | `python/backend/science.py` و`python/export_web.py` |

تعديل الواجهة لا يحتاج توليد المدارات. بعد تعديل البيانات العلمية عمدًا، استخدمي `REBUILD_DATA_WINDOWS.bat` مرة واحدة وحدّثي التقييم المرتبط بالبيانات. هذه عملية مستقلة عن فتح الموقع.

تقارير V2 السابقة محفوظة كمرجع للبيانات الأساسية، لكنها تصف واجهة سابقة عند اختلافها مع V2.1. النسخ الاحتياطية موجودة في `source_backup` و`python/backups`؛ يمكن فتح هذه النسخة في مجلد مستقل عن مشروعك القديم.
