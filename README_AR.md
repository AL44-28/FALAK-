# نشر فلك على حسابك في GitHub

1. فكّي ضغط FALAK_GitHub_Upload.zip.
2. في حسابك على GitHub أنشئي مستودعًا Public باسم falak (أو أي اسم تختارينه)، وفعّلي Add a README file ثم Create repository.
3. افتحي Add file → Upload files. ارفعي محتويات الملف بعد فك الضغط مباشرة: index.html مع assets وdata وvendor وبقية ملفات JavaScript وCSS و.nojekyll. يجب أن يظهر index.html في الصفحة الرئيسية للمستودع.
4. اضغطي Commit changes إلى main.
5. افتحي Settings → Pages. اختاري Deploy from a branch، ثم main، ثم /(root)، ثم Save.
6. بعد نجاح النشر يظهر رابط الموقع في Pages؛ افتحي Visit site.

هذه الحزمة معدّة للنشر من جذر الفرع، ولا تحتاج ملف GitHub Actions. لا تحتاج Python مثبتًا أو تشغيل سيرفر على جهازك لزيارة الموقع المنشور.

الحفظ في السيناريوهات: اضغطي Save changes بعد تعديل الكود أو الاسم. تبقى التعديلات في نفس المتصفح وعلى نفس رابط الموقع. Export workspace ينزل نسخة احتياطية للأكواد والأسماء، وImport workspace يعيدها. صدّري النتائج والبلوت منفصلًا إذا أردت الاحتفاظ بها بعد إعادة التحميل.

المحتوى محاكاة اصطناعية. عند أول تشغيل لكود Python داخل السيناريوهات، يُحمّل Pyodide من الإنترنت. الداشبورد نفسه لا ينتظر هذا التحميل.

تتضمن النسخة الشعار الجديد والخريطتين المكبرتين والألوان الواضحة وأربع سيناريوهات وتبطيء العرض للنصف عند المرور فوق السعودية. اجتازت اختبارات الحفظ والتوقيت وسلامة البيانات. تعذرت المعاينة البصرية أثناء التجهيز بسبب خطأ أداة المتصفح.
